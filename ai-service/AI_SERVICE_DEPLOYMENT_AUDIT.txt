CRITICAL DEPLOYMENT WARNINGS FOR RENDER:
1. PyTorch / sentence-transformers RAM Footprint:
   `sentence-transformers` automatically pulls `torch` during `pip install`. Installing and loading `torch` + model `all-MiniLM-L6-v2` in memory requires at least 600MB - 1GB RAM.
   Render's Free Tier has a strict 512MB RAM limit. Deploying on Free Tier WILL cause Out-Of-Memory (OOM) crashes during start up or request handling.
   ACTION REQUIRED: Render instance tier MUST be Starter (1GB RAM) or higher.

2. Build Timeouts:
   Installing `pyarrow`, `pandas`, `scikit-learn`, and `torch` during `pip install` on Linux takes 2-4 minutes. Render build timeout is 15 minutes (sufficient, but pre-built wheels must be downloaded).

- Service 2: `app/services/gtts_service.py` (Google Text-to-Speech Integration)
  - Free, open-source Google Translate TTS engine wrapper (`gtts` package)
  - Runs in asyncio thread executor (`loop.run_in_executor`)
  - Supports English ('en') and Hindi ('hi') natively without API keys.

Active Worker Voice Summary API:
- Endpoint: `POST /ai/worker/voice-summary` (`app/api/worker_voice_summary.py`)
- Active Pipeline:
  1. Validates worker Bearer token via backend `/api/v1/auth/me`
  2. Generates 2-3 sentence English or Hindi summary via Groq LLM
  3. Synthesizes MP3 audio bytes using `gtts_service`
  4. Encodes MP3 bytes to base64 and returns JSON payload to Flutter client
- Audio Delivery: Returned in-memory as base64 string in JSON (no files written to disk, no ffmpeg system package required).
